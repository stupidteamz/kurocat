<details>
<summary>🪟 <b>Windows 안내</b>: 브라우저 경고 · SmartScreen · WebView2 누락</summary>

<br />

- **브라우저 `.exe` 경고** (상용 EV 코드 서명 없는 무료 오픈소스 빌드):
  - **Edge**: 다운로드 항목에 마우스 오버 → `···` → **유지** → `▾` → **계속 유지**.
  - **Chrome**: `Ctrl + J` → **위험한 파일 보관** → **계속**.
  - **Windows SmartScreen**: **추가 정보** → **실행**.
- **WebView2 누락 (구형 Win10 / LTSC)**: Microsoft 공식 [`MicrosoftEdgeWebview2Setup.exe`](https://go.microsoft.com/fwlink/p/?LinkId=2124703)를 관리자 권한으로 설치하세요.

</details>

<details>
<summary>🍎 <b>macOS 첫 실행 및 권한 설정</b>: 격리 해제 · 손쉬운 사용 &amp; 입력 모니터링</summary>

<br />

- **`.dmg` 수동 설치 시 "개발자를 확인할 수 없음 / 손상됨" 경고** (Homebrew 설치 시 자동 처리):
  ```bash
  xattr -cr /Applications/KuroCat.app && open /Applications/KuroCat.app
  ```
- **전역 키보드·마우스 반응**: **시스템 설정 → 개인정보 보호 및 보안**에서 **손쉬운 사용**과 **입력 모니터링** 모두에서 `KuroCat`을 활성화하세요 (Karabiner-Elements 호환).

</details>

<details>
<summary>🎮 <b>게임 전체화면 · OBS 투명 방송 소스 · 안티치트 안전 모드</b></summary>

<br />

- **게임 위 항상 표시**: 창 모드/테두리 없는 전체화면에서 포커스를 뺏지 않고 최상단 유지 (**클릭 투과 잠금** 권장, `Alt`로 임시 이동). 관리자 권한 게임은 트레이에서 **관리자 권한으로 재시작**하세요.
- **OBS 투명 브라우저 소스**: 우클릭 → **OBS 투명 소스 URL 복사** (`http://127.0.0.1:27421/obs`)로 크로마키 없는 네이티브 Alpha 투명 채널 지원 (**OBS 전용 모드** 및 비밀번호 보호 연동).
- **커널 안티치트 게임** (발로란트 등): 실행 전 트레이에서 **감시 일시 중지 및 숨기기**를 선택하면 입력 훅이 완전히 해제됩니다.

</details>

<details>
<summary>🐧 <b>Linux 요구 사항</b></summary>

<br />

- Ubuntu 22.04 기준 빌드로 **`glibc >= 2.34`**가 필요합니다.
- `.deb` 패키지는 `libwebkit2gtk-4.1-0` 및 `libayatana-appindicator3-1` 필요; `.AppImage`는 관리자 권한 없이 실행 가능합니다.
- 루트 없이 X11 `XRecord` 전역 입력을 동적 로드하며, Wayland에서는 `evdev`로 자동 폴백합니다.

</details>

## 🤖 AI 동반자 &amp; MCP 커스텀 스튜디오

단일 실행 파일에 **Stdio** 및 로컬 **Streamable HTTP (`127.0.0.1:27420`)** MCP 서버가 기본 내장되어 있습니다 (Node.js / Python 불필요):

1. KuroCat 실행 후 우클릭 → **MCP 확장 켜기** → **MCP 설정 복사**.
2. **Claude Desktop / Cursor / Antigravity / Windsurf**에 붙여넣고 자연어로 요청하세요:

> 💬 *"우리 집 삼색 고양이 사진이야. KuroCat MCP로 귀 모양과 무늬까지 맞춘 3D 데스크톱 펫을 만들어 바로 전환해 줘!"*  
> 💬 *"크기를 85%로 조정하고 108키 시청자 시점으로 바꾼 뒤 키 버블을 꺼 줘."*

<details>
<summary>📋 <b>Stdio / HTTP 설정 JSON 및 내장 10개 MCP 도구 목록 보기</b></summary>

<br />

```json
{
  "mcpServers": {
    "kurocat": {
      "url": "http://127.0.0.1:27420/mcp"
    }
  }
}
```

| 도구 | 설명 |
| --- | --- |
| `list_cats` | 모든 기본·커스텀 스킨 및 현재 활성 캐릭터 조회 |
| `get_cat_schema` | 전체 털 무늬, 16개 반점 좌표 및 7가지 2D/3D 윤곽 스키마 조회 |
| `upsert_cat` | 커스텀 고양이 생성·수정 및 0.4초 실시간 반영 |
| `patch_cat` | 기존 또는 기본 스킨 부분 미세 조정 |
| `switch_cat` | ID로 데스크톱 캐릭터 즉시 전환 |
| `delete_cat` | 커스텀 고양이 삭제 (또는 기본 스킨 초기화) |
| `get_settings` / `update_settings` | 크기, 키보드 배열, 버블, 골골송, 클릭 투과, 자동 실행 설정 변경 |
| `set_agent_status` | AI 코딩 에이전트 상태 (생각/코딩/명령 실행/대기/오류/완료) 동기화 |
| `trigger_action` | 쓰다듬기·기쁨·화남·낮잠 등 인터랙션 애니메이션 실행 |

</details>
