🛡️ Windows 浏览器提示「通常不会下载 .exe / 保护你的电脑」怎么办？

由于本项目为免费开源软件、未购买商业 EV 代码签名证书，Edge 浏览器在下载新版本 .exe 时可能会弹出「通常不会下载」提示（全部源码已在 GitHub 公开，可放心使用）：
① Edge 浏览器保留步骤：鼠标移到下载记录上 → 点右侧三个点 ··· → 点「保留」 → 弹窗显示「删除」按钮时，点击旁边的下箭头 ▾（显示更多） → 选择「仍然保留」即可下载完成（Chrome 请按 Ctrl + J 打开下载页 → 点「保留危险文件」→「仍然保留」）。
② 双击安装若弹出蓝框「Windows 已保护你的电脑」：点击「更多信息」 → 点击「仍要运行」即可完成安装。

🍺 macOS Homebrew 一键安装（推荐 · 自动免隔离）

已上线官方 Homebrew Tap（qianyiai/homebrew-tap），终端执行右侧一行命令即可直接安装并自动清理隔离属性（免手动 xattr），后续可随时运行 brew upgrade --cask kurocat 一键升级。

brew install --cask qianyiai/tap/kurocat
🍎 macOS 首次打开说明（仅需一次 · 无需开着终端）

由于本项目为免费开源未公证应用，首次拖入「应用程序」后若提示「无法验证开发者」或「已损坏」，请勿进入包内容用终端运行，只需打开一次终端粘贴执行右侧命令即可彻底解除隔离（跑完可关闭终端，后续直接双击图标打开）。全局键鼠响应请在「系统设置 → 隐私与安全性」中同时勾选「辅助功能」与「输入监控」里的 KuroCat，即开即生效（兼容 Karabiner-Elements）。

xattr -cr /Applications/KuroCat.app && open /Applications/KuroCat.app
🪟 Windows 提示「Could not find the WebView2 Runtime」怎么办？

常见于较老 Win10 / LTSC 精简版、卸过 Edge 浏览器或直接运行绿色单文件版的电脑（Win7 用户请直接下载下方专属兼容绿包版）。优先推荐安装上方正式安装版（setup.exe），或点击右侧下载微软官方 WebView2 引导程序（1.8 MB），右键 → 以管理员身份运行装完即可全机生效。

🎮 游戏全屏 / OBS 直播怎么显示小黑猫？（含反作弊安全提示）

① 单机与常规游戏：在 Win10/11 全屏优化（FSO）或「无边框窗口化」下内置持续 Z 序置顶守卫且绝不抢焦点；建议开启「锁定鼠标穿透」（按住 Alt 键随时临时拖动或右键解锁）。若游戏以管理员权限运行导致无法捕获键鼠，右键系统托盘点「以管理员身份重启（捕获游戏键鼠）」即可。 ② OBS 直播 / 录屏（原生免抠像）：右键小猫或系统托盘点「复制 OBS 透明源地址」（自动开启本机 http://127.0.0.1:27421/obs，默认关闭零开销），在 OBS 添加「浏览器」来源即可直接获得原生 Alpha 透明通道（无需绿幕抠像，支持「仅 OBS 显示」隐藏桌面猫，密码防偷窥同步生效）。 ③ 强内核反作弊网游（无畏契约、三角洲行动等）：建议游玩前右键系统托盘点一下「暂停监听并隐藏（游戏反作弊护航）」，彻底卸载钩子保护账号安全。
