
<details>
<summary>🪟 <b>Windows の注意点</b>：ブラウザ警告・SmartScreen・WebView2 不足</summary>

<br />

- **ブラウザの `.exe` 警告**（商用 EV コード署名証明書なしの無料オープンソース配布のため）：
  - **Edge**：ダウンロード項目にホバー → `···` → **保存** → 「削除」横の `▾` → **保持する**。
  - **Chrome**：`Ctrl + J` → **危険なファイルを保存** → **続行**。
  - **SmartScreen 青画面**：**詳細情報** → **実行**。
- **WebView2 不足（旧 Win10 / LTSC 等）**：Microsoft 公式 [`MicrosoftEdgeWebview2Setup.exe`](https://go.microsoft.com/fwlink/p/?LinkId=2124703) を管理者として実行してください。

</details>

<details>
<summary>🍎 <b>macOS 初回起動と権限設定</b>：隔離解除・アクセシビリティ＆入力監視</summary>

<br />

- **`.dmg` 手動導入で「開発元を確認できない / 壊れている」と表示された場合**（Homebrew 導入時は自動処理）：
  ```bash
  xattr -cr /Applications/KuroCat.app && open /Applications/KuroCat.app
  ```
- **グローバル入力の有効化**：「システム設定 → プライバシーとセキュリティ」で **アクセシビリティ** と **入力監視** の両方で `KuroCat` をオンにしてください（Karabiner-Elements 互換）。

</details>

<details>
<summary>🎮 <b>フルスクリーンゲーム・OBS 透過配信・アンチチート対策</b></summary>

<br />

- **ゲーム前面表示**：ボーダーレスウィンドウ／FSO 下でフォーカスを奪わず最前面表示（**クリック透過ロック** 推奨、`Alt` で一時移動）。管理者権限のゲームではトレイから **管理者として再起動** してください。
- **OBS 透過ブラウザソース**：右クリック → **OBS 透過ソース URL をコピー**（`http://127.0.0.1:27421/obs`）でクロマキー不要の Alpha 透過表示に対応（**OBS のみ表示**＆パスワード目隠し同期）。
- **カーネル級アンチチート搭載ゲーム**：起動前にトレイから **監視を一時停止して非表示** を選ぶとフックを完全解除します。

</details>

<details>
<summary>🐧 <b>Linux 動作要件</b></summary>

<br />

- Ubuntu 22.04 ベースでビルドされており **`glibc >= 2.34`** が必要です。
- `.deb` は `libwebkit2gtk-4.1-0` と `libayatana-appindicator3-1` に依存；`.AppImage` は管理者権限なしで起動可能。
- X11 `XRecord` を動的ロード（root 不要）し、Wayland では `evdev` へ自動フォールバックします。

</details>

## 🤖 AI 相棒 &amp; MCP カスタマイズ

単体バイナリに **Stdio** とローカル **Streamable HTTP（`127.0.0.1:27420`）** の MCP サーバーを内蔵（Node.js / Python 不要）：

1. KuroCat を起動し、右クリック → **MCP 拡張を有効化** → **MCP 設定をコピー**。
2. **Claude Desktop / Cursor / Antigravity / Windsurf** に貼り付けて自然言語で指示：

> 💬 *「うちの三毛猫の写真を見て、KuroCat MCP で耳の形と模様を合わせた専用 3D ペットを作って切り替えて！」*  
> 💬 *「サイズを 85% にして、108 キー視聴者視点に切り替え、キーバブルをオフにして。」*

<details>
<summary>📋 <b>Stdio / HTTP 設定 JSON と内蔵 10 MCP ツール一覧を開く</b></summary>

<br />

```json
{
  "mcpServers": {
    "kurocat": {
      "url": "http://127.0.0.1:27420/mcp"
    }
  }
}
```

| ツール | 機能 |
| --- | --- |
| `list_cats` | 内蔵・カスタムスキン一覧と現在アクティブな猫を取得 |
| `get_cat_schema` | 模様・16 スポット座標・7 種の 2D/3D 輪郭スキーマを取得 |
| `upsert_cat` | カスタム猫を作成・更新し 0.4 秒でホットリロード |
| `patch_cat` | 既存または内蔵スキンを部分微調整 |
| `switch_cat` | ID 指定で即座にスキン切替 |
| `delete_cat` | カスタム猫を削除（または内蔵スキンをリセット） |
| `get_settings` / `update_settings` | ズーム・配列・バブル・ゴロゴロ音・透過ロック等を変更 |
| `set_agent_status` | AI エージェント状態（思考／実装／実行／待機／エラー／完了）を同期 |
| `trigger_action` | なでなで・喜び・怒り・居眠りアクションを再生 |

</details>
